Message flow

1Identity keys authenticate the participants and provide public key material.
2DH-based key agreement contributes shared secret material to the session.
3The Signal Protocol session derives cryptographic state.
4The Double Ratchet advances keys as messages are sent.
5A fresh message key protects the plaintext before transmission.
6The server relays ciphertext; Bob decrypts on his device.
